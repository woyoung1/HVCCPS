# MCU reference documentation / MCU 参考资料

STMicroelectronics documentation is linked here instead of being copied into the repository. Always check the revision shown on the official download page before using register descriptions, electrical limits, or bootloader details.

本仓库仅记录 STMicroelectronics 官方资料链接，不保存厂商手册副本。使用寄存器说明、电气极限或 Bootloader 信息前，请确认官方下载页显示的最新版本。

项目实际采用的配置和行为以仓库 README、源码及源码注释为准；厂商资料的授权条款和版本历史仍由 STMicroelectronics 管理。
